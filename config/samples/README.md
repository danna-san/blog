# 文章サンプル置き場

ここに、自分が過去に書いた文章（日記、SNS の投稿、メールの下書きなど）を `.md` か `.txt` で置くと、
文体の参考として文章生成に渡されます。内容（出来事）は使われず、書きぶりだけを参考にします。

- ファイル名は自由です（例: `2025-diary-01.md`）。名前の新しい順（逆順）に、合計 `blog.config.json` の `ai.sampleMaxChars` 文字（既定 6000）まで使います。
- このファイル（README.md）は渡されません。
- **リポジトリは公開されています。** 人に見られて困る文章や、個人が特定できる情報は置かないでください。
- 置かなくても動きます（その場合は `config/persona.md` の質問票だけで文体を決めます）。
